# CEBRASPE
- #banca/cebraspe 

- Para ser uma entidade **associativa** precisaria ser um <mark style="background:rgba(5, 117, 197, 0.2)">relacionamento muitos para muitos</mark>;
Relacionamentos:
1:1 (Fusão de tabelas);
1:N ( Criação de mais uma coluna do lado N com a chave estrangeira do lado 1);
N:N ( Criação de mais uma tabela chamada de ''entidade associativa a qual herda a chave primária das outras duas tabelas).

- A **modelagem do tipo relacional** organiza os dados em forma de **tabelas**, **com linhas e colunas**, e utiliza os elementos de medidas e dimensões.
- Logo, no modelo relacional de dados todas as relações necessitam de uma chave primária formada por uma ou mais ~~tuplas~~ <mark style="background:#fff88f">colunas</mark> que identificam um único registro <mark style="background:rgba(74, 82, 199, 0.2)">/ linha/ tupla.</mark>
<mark style="background:rgba(5, 117, 197, 0.2)">- Tuplas = linhas = registros = instâncias;</mark>
<mark style="background:rgba(5, 117, 197, 0.2)">- Colunas = Campos = Atributos = Domínios = Cabeçalhos;</mark>
<mark style="background:rgba(5, 117, 197, 0.2)">- Tabelas = Relações = Entidades.</mark>

- **ITEM CERTO**. Em questões de concurso, especialmente aquelas que abordam conceitos teóricos de normalização, o foco está no entendimento **canônico** das formas normais. Nesse contexto, a 5FN é considerada a forma normal que elimina todas as anomalias **passíveis de serem resolvidas por projeções**.
