### Sistema de Amortização Constante (SAC)
(https://www.tecconcursos.com.br/aulas/materias/20/assuntos/714?indice=1&materia=713)

(Esaf) Um financiamento no valor de R$ 360.000,00 deve ser pago em 180 prestações mensais, pelo Sistema de Amortizações Constantes - SAC, a uma taxa nominal de 12% ao ano, vencendo a primeira prestação ao fim do primeiro mês, a segunda ao fim do segundo mês e assim sucessivamente. Calcule o valor mais próximo da décima prestação.
a) R$ 5.600,00
b) R$ 5.420,00
c) R$ 5.400,00
d) R$ 5.380,00
e) R$ 5.500,00
**Resolução:**
A amortização mensal é dada por:
q=360.000/180=2.000
Após a nona prestação, já teremos amortizado 9 vezes a dívida:
9×2.000=18.000

A dívida remanescente será de:

360.000−18.000=342.000

No décimo mês, teremos juros de 1% incidindo sobre o valor acima:

J10=1%×342.000=3.420

Além disso, teremos o pagamento da amortização de 2.000,00. Somando tudo, a prestação será de:
2.000+3.420=5.420

- **Regime composto** - Os montantes foram uma P.G.. de razão (1+I)(1+I), ou seja, existe um crescimento exponencial.

|   |   |
|---|---|

|0<n<1|O montante simples é maior do que o montante composto.|
|n>1|O montante simples é menor do que o montante composto.|

**2. TAXAS EQUIVALENTES**

- Duas taxas são ditas equivalentes quando, aplicadas a um mesmo capital inicial, pelo mesmo prazo, produzem o mesmo montante. 
- No regime simples, taxas proporcionais são equivalentes, portanto, para se achar a taxa equivalente, basta usar regra de três.
- No regime composto, taxas proporcionais não são equivalentes, portanto, é necessário igualar montantes compostos: 
- M1=M2M1​=M2​, logo: (1+i1)ˆn1=(1+i2)ˆn2(1+i1​)ˆn1​=(1+i2​)ˆn2​

Onde, 

- M1,M2M1​,M2​: montantes.
- i1,i2i1​,i2​: taxas de juros.
- n1,n2n1​,n2​: períodos.

**3. TAXA NOMINAL**

- Quando o período da taxa não coincide com o período da capitalização. 
- Exemplo: 24% ao ano com capitalização mensal. No exemplo, a taxa nominal é 24% ao ano e a efetiva é de 2% ao mês
- Para cálculos, usar-se-á a taxa EFETIVA. Além disso, a efetiva é **sempre** encontrada por proporcionalidade, independente do regime.

**4. TAXA EFETIVA**

- Quando o período da taxa coincide com o período da capitalização. 
- Exemplo: 2% ao mês com capitalização mensal.

**EQUIVALÊNCIA DE CAPITAIS**

**1. TEORIA**

Dinheiro tem valor no tempo. Isso quer dizer que 10 reais hoje têm valores diferente no futuro e no passado, mesmo assim, esses valores são ditos equivalentes.

Dois ou mais conjuntos de capitais, com datas diferentes, são ditos equivalentes quando, transportados para uma mesma data, a uma mesma taxa de juros, produzem, nessa data, valores iguais - perceba, entretanto, que equivalência não é igualdade.

Se dois conjuntos de capitais são equivalentes em determinada data focal, então eles também serão equivalentes em qualquer outra data focal. 

Assim, para resolver os problemas de equivalência composta de capitais, podemos escolher qualquer data para ser a data focal.

Nunca podemos comparar dois valores que estão em datas diferentes. 

O valor do dinheiro está diretamente associado a uma data. 

Perceba, então, que tudo em matemática financeira gira em torno do conceito de Equivalência de Capitais: 

- Operações de juros: transporte de C (capital inicial) para o futuro, encontrando M (montante);
- Operações de desconto: transporte de N (valor nominal) para o passado, encontrando A (valor atual)

**2. PRÁTICA**

**2.1. FÓRMULA**

- F=A.(1+i)nF=A.(1+i)n 

onde:

- F: valor futuro;
- A: valor atual (muitas vezes denotado por P, como valor presente);
- i: taxa de juros;
- n: período.

**2.2. USO**

- Para avançar um valor para o futuro, multiplicamos por (1+i)n(1+i)n
    
- Para retroceder um valor para o presente, dividimos por (1+i)n(1+i)n
    
- Dado que, para analisar a equivalência de capitais será necessário escolher uma data focal, é recomendado escolher uma data futura, pois transportar valores por multiplicação é mais fácil que fazê-lo por meio de divisão.

**1 ELEMENTOS DE UMA SÉRIE UNIFORME**

- Intervalo de tempo de pagamento: é o intervalo de tempo entre 2 pagamentos seguidos. 
- Anuidade ou renda: é o valor de cada pagamento efetuado em intervalos de tempo iguais. 

**2 TIPO DE RENDAS**

**2.1 ANTECIPADAS X POSTECIPADAS**

- Antecipadas: pagamentos efetuados no início de cada período (no ato do negócio).
- Postecipadas: pagamentos efetuados no final de cada período (um período após a negociação do negócio). 

**2.2 IMEDIATAS X DIFERIDAS**

- Imediatas: quando o primeiro pagamento é efetuado no primeiro período. 
- Diferidas: quando houver carência para o pagamento da primeira anuidade.

**1. SISTEMA DE AMORTIZAÇÃO CONSTANTE (SAC)**

- As prestações são decrescentes 
- Os juros são decrescentes 
- O juro pago em cada prestação é calculado incidindo a taxa de juros sobre o saldo devedor do período anterior.

**4. SISTEMA DE AMORTIZAÇÃO MISTO | SISTEMA AMERICANO DE AMORTIZAÇÃO | SINKING FUND (FUNDO DE AMORTIZAÇÃO)**

**4.1 SISTEMA DE AMORTIZAÇÃO MISTO (SAM)**

- A prestação do SAM é obtida pela média aritmética entre as prestações do SAC e do sistema francês (tabela price). 
- PSAM=(PSAC+PSF)/2PSAM​=(PSAC​+PSF​)/2
- Há autores que chamam o SAM de SACRE - Sistema de Amortização Crescente. 

**1. ANÁLISE DE INVESTIMENTOS**

**1. TAXA MÍNIMA DE ATRATIVIDADE (TMA)**

- Não existe uma fórmula única para se calcular a TMA.
- A TMA também é conhecida como custo de capital. 
- É a menor taxa que o investidor aceita para entrar no projeto. 
- A TMA geralmente deriva do Custo de Oportunidade ou WACC (uma fórmula que você, concurseiro, não precisa conhecer).

**2. FLUXO DE CAIXA** 

- Graficamente, setas para cima representam recebimento (positivo) e setas para baixo pagamentos (negativo). 
- Em questões teóricas, costuma-se representar valores positivos e negativos diretamente, sem flechas.

**3. VALOR PRESENTE LÍQUIDO (VPL)**

- É a soma algébrica dos valores presentes (data 0) dos fluxos de caixa, valor obtido mediante o desconto dos fluxos de caixa (positivos e negativos) a uma taxa de reflita o custo de oportunidade do capital investido. 
- No método do VPL, utilizaremos a TMA como taxa para efetuar o transporte dos valores.
- Para calcular o VPL, devemos transportar todos os valores para a data 0 e realizar a soma algébrica. 
- Quanto maior o VPL, melhor é o projeto. 
- Caso haja 2 ou mais formas de investimento, será escolhida aquela que possuir o maior VPL. 
- Caso haja apenas 1 alternativa para o projeto, o VPL de seu fluxo de caixa indicará se o projeto é viável, inviável ou indiferente. 
    - Se VPL > 0, o projeto é viável. 
    - Se VPL < 0, o projeto é inviável
    - Se VPL = 0, o projeto é indiferente.

**5. TAXA INTERNA DE RETORNO (TIR)**

- Taxa de juros que anula o VPL do fluxo de caixa do investimento (VPL=0)
- A TIR indica o quanto o capital rendeu no projeto.
- Em fluxos de caixa em que há alternância entre recebimentos e pagamentos, é possível existir mais de 1 TIR ou nenhuma TIR. Nesse caso, o método se torna inconclusivo 
- A TIR supõe que os recebimentos serão aplicados à mesma taxa do projeto, o que nem sempre é verdade. Por isso, foi criada a TIRM - último tópico do bizu.

**6. RELAÇÃO ENTRE VPL, TMA E TIR**



                                                                                         Fonte: ChatGPT (2025)

- Se TMA > TIR, então VPL < 0
- Se TMA = TIR, então VPL = 0
- Se TMA < TIR, então VPL > 0

**7. TIR MODIFICADA (TIRM)**

- Resolve-se o problema de alternância de fluxos presentes na análise por meio da TIR, trazendo os fluxos de caixa negativos para o valor presente e os fluxos de caixa positivos para o valor valor futuro.
- Como benefício adicional, pode-se trabalhar com duas taxas: taxa de financiamento e taxa de reinvestimento (geralmente, TMA)

**8. TIR INCREMENTAL** 

- Diferente da TIR simples, a TIR incremental compara dois projetos mutuamente exclusivos, avaliando o retorno gerado pelo investimento adicional entre eles.
